# Piano reference notes

The six WAV files are short, mono derivatives of the medium-velocity recordings
from [Splendid Grand Piano](https://github.com/sfzinstruments/SplendidGrandPiano)
(Steinway piano samples released into the public domain by AKAI). The source is
pinned to commit `1c595d827b7fd7f0be3134aaed0f90b3662a09cf`; the source
filenames and WAV conversion are recorded in `tool/prepare_piano_samples.py`.

Each note was trimmed to 2.8 seconds, normalized conservatively, and given a
short fade-out. These are bundled reference sounds, not recordings from YouTube.
